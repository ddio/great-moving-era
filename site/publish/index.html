怎麼分享給搬家公司

做好之後有三種給法。不確定選哪個，就用第一個：大部分搬家公司都習慣收 PDF。

最簡單

傳 PDF

下載 PDF，用 LINE 或 Email 傳過去。不用註冊任何東西。

 想要一個網址

Netlify Drop

把資料夾拖進網頁就上線。要保留網址得註冊免費帳號。

 已經有 Cloudflare 帳號

Cloudflare Pages

可以直接拖 zip 檔，不用解壓縮。

先在自己電腦上看看

下載的網站檔不用放上網路也能看：

  1. 在編輯頁按「更多 → 下載網站檔（兼備份）」。
  2. 先解壓縮，會得到一個 moving-site 資料夾。Windows 可以直接點進 zip 裡面，但在那裡打開的話照片會出不來。
  3. 點兩下資料夾裡的 index.html，就會用瀏覽器打開，和搬家公司看到的一模一樣，不需要網路。

放上網路之前先這樣檢查一遍，也可以把整個資料夾用隨身碟帶著。

傳 PDF

  1. 在編輯頁右上角按「下載 PDF」。第一次會先下載中文字型（約 6MB），之後就不用。
  2. 用 LINE、Email 或任何通訊軟體傳給搬家公司。

PDF 裡的照片是縮圖，幾十張照片通常 5MB 左右，Email 附件也放得下。想看大圖的搬家公司，可以另外給網址版。

不要用瀏覽器的「列印 → 另存 PDF」：只要縮放不是 100%，照片會被轉成超大的點陣圖，同樣的內容可能從 5MB 變成幾百 MB。請用編輯頁的「下載 PDF」。

Netlify Drop：拖進去就有網址

  1. 在編輯頁按「更多 → 下載網站檔（兼備份）」，會得到一個 zip 檔。
  2. 解壓縮，會得到一個 moving-site 資料夾。
  3. 打開 app.netlify.com/drop，把整個 moving-site 資料夾拖進虛線框。Netlify Drop 只收資料夾，不收 zip。
  4. 幾秒後會出現一個網址，長得像 https://random-name-123abc.netlify.app，複製起來傳給搬家公司。

沒登入就上傳的網站只是暫時的，要在一小時內按畫面上的提示註冊（可以用 Google 帳號）才會保留下來。建議先登入再拖。

內容改了怎麼辦

重新下載網站檔、解壓縮，到 Netlify 那個網站的 Deploys 頁面，把新資料夾拖到頁面下方的框裡。網址不會變。

Cloudflare Pages

  1. 在編輯頁按「更多 → 下載網站檔（兼備份）」。
  2. 登入 Cloudflare，到 Workers & Pages，選 Create application，再選 Drag and drop your files。
  3. 幫專案取個名字，名字會變成網址：名字.pages.dev。取一個別人猜不到的名字，不要用自己的姓名或地址。
  4. 把 zip 檔直接拖進去，按 Deploy。

內容改了怎麼辦

到那個專案按 Create a new deployment，拖入新的 zip 檔。

放上網路之前

  • 拿到網址的人都看得到全部內容，沒有密碼保護。網址只給搬家公司，不要貼在社群上。
  • 網站已經設定成不讓搜尋引擎收錄，但網址本身還是唯一的門檻。
  • 地址寫到路段、聯絡人寫「王小姐」就夠了，正式委託時搬家公司會再跟你要完整資料。
  • 搬完家記得把網站刪掉。Netlify 在網站的設定頁最下面、Cloudflare 在專案的 Settings 最下面，都有刪除按鈕。
