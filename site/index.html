全部都放在這裡了！

拍照、填一填，做出一頁搬家公司看了就能報價的家當說明。不用一家一家約看屋，也不用在電話裡比手畫腳。

開始整理我的家當 先看範例

免費、免註冊、免安裝。資料只存在你自己的電腦裡。

詢價的時候，你是不是也經歷過這些？

搬家公司請問大概有多少東西？

你呃……一些？一個家的量？

搬家公司那我們約個時間去現場看一下。

你（內心）問五家，就要請五天假……

  • 在電話裡形容沙發有多大，雙手張開，對方看不到
  • 每一家都要從頭講一遍：幾樓、有沒有電梯、貨車停哪裡
  • 搬家當天：「欸，這台洗衣機你沒說喔，要加錢。」

於是我把整個家寫成一頁網頁，傳給每一家。
然後就沒人再賴我問搬家資訊了。

一頁寫清楚，搬家公司最想知道的全部

同一份說明給每一家，報價才比得起來。白紙黑字寫過的東西，搬家當天也比較不會「欸你沒說」。

內容物 易碎 小心輕放
  • 搬運條件幾樓、有沒有電梯、貨車能停多近、哪天搬
  • 每個房間格局照、細節照，哪些要搬、哪些不用
  • 大型家具尺寸、能不能拆、要特別小心的地方
  • 平面圖一眼看懂動線
  • 手機、電腦、紙本都能看，也能存成 PDF 用 LINE 丟

三個步驟，比打包簡單多了

  1. 拍照

    每個房間拍幾張全景，特別難搬的東西拍細節。

  2. 填寫

    把照片拖進房間，寫下要搬的東西和注意事項。

  3. 分享

    下載成網站或 PDF，丟給搬家公司，等報價。

你的家當，只放在你的電腦裡

照片和內容都在你的瀏覽器裡處理，不會上傳到我們的伺服器。照片裡的 GPS 位置和拍攝資訊會自動移除，搬家公司不會知道你家在哪顆衛星底下。

地址寫到路段就好，例如「新店區北新路三段」。真的要委託時，搬家公司自然會跟你要完整地址，現在不用急著交出去。

常見問題

要錢嗎？

不用。程式碼放在 GitHub 上，想看、想改都可以。

要安裝什麼嗎？

不用，打開瀏覽器就能做。建議用電腦，一次整理幾十張照片會比較順手。

做到一半關掉，會不會全部不見？

不會，內容會自動存在這台電腦的瀏覽器裡。但換電腦或清除瀏覽器資料就真的不見了，記得按「下載備份」。

這是本站唯一會讓你失去家當的方式，機率比搬家公司摔壞東西還高，請認真看待。

做好之後怎麼給搬家公司？

最簡單的是下載 PDF，直接用 LINE 或 Email 傳。想要一個網址的話，把下載的網站拖進免費的網頁空間就好，步驟在這裡。

搬家公司要裝什麼才能看？

什麼都不用。點開網址或 PDF 就能看。

用完之後，要怎麼把資料刪掉？

在編輯頁最下面「搬完家了？」按「刪除這台電腦上的資料」，瀏覽器裡的內容和照片會整個刪除。下載過的 PDF、網站檔，以及放上網路的網站要另外刪，放上網路的怎麼刪。

iPhone 拍的照片可以用嗎？

可以。iPhone 預設的 HEIC 格式只有 Safari 讀得懂；用其他瀏覽器的話，請先在 iPhone「設定 → 相機 → 格式」改成「最相容」再拍，或傳到電腦時選 JPEG。
